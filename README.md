An exact interpreter for make.fun's tiny stack ISA: wrapping 32-bit arithmetic (Math.imul, unsigned DIVU/MODU/LTU, 5-bit shift counts), a 256-value stack, a 64-deep call stack, 256 words of memory, and all ten traps with their own exit codes, every check in the ISA's order under the 1,000,000-step and 65,536-byte limits. Per-opcode tables drive one typed-array dispatch loop, so a 40-instance set finishes far inside the 60-second wall.
